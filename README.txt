1. ARCHIVOS INCLUIDOS
- generador_instancias.py: Script proporcionado para crear los datos de la práctica (exámenes, alumnos, aulas).
- practica1.py: Código principal. Se lleva a cabo todo lo solicitado en el enunciado.
- graficas.py: Script adicional para generar las dos gráficas comparativas de la memoria.

2. REQUISITOS PREVIOS
Es necesario tener instalado Python y las siguientes librerías:
- numpy
- pandas
- matplotlib


3. INSTRUCCIONES DE EJECUCIÓN
Para ejecutar la práctica entera y ver los resultados de los algoritmos:
1. Abrir una terminal en esta misma carpeta.
2. Ejecutar el comando:
   python practica1.py

Esto mostrará por pantalla el coste inicial, el coste de cada algoritmo, las evaluaciones hechas y los segundos que ha tardado para la Instancia Pequeña, Mediana y Grande.
